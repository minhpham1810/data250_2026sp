# DATA 250 — 2026sp

Coursework for DATA 250 (Spring 2026): labs and projects covering data loading,
cleaning, and analysis with Python, numpy, and pandas.

## Structure

- `Lab00`–`Lab10`: weekly lab notebooks and supporting data files.
- `Project 1`–`Project 4`: project notebooks, write-ups, and datasets.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Then open any notebook with Jupyter:

```bash
jupyter notebook
```
